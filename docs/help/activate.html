注册与激活

说明 本章所说的「账号」是 RC3 软件的授权账号，与系统内部的操作员登录账号是两回事，两者互不影响。

一、为什么需要注册与激活

RC3 企业管理系统为授权使用软件。首次在一台新电脑上运行时，系统中还没有本机的许可证，启动时会提示：

未检测到许可证文件，请先注册和激活。

完成「注册」与「激活」两步之后，才能进入系统主界面。

步骤 作用 输入内容 结果
注册 提交邮箱与设备码，向公司申请授权 登录邮箱、登录密码 许可证密钥发送到注册邮箱
激活 用收到的密钥为本机授权 许可证密钥 本机获得授权，可正常使用

二、「注册与激活」窗口

窗口标题为 注册与激活，从上到下分为四个区域：

1. 账号注册（窗口顶部）

  • 链接 「还没有账号？立即注册」：点击后自动打开浏览器，进入官网注册页 https://richen.dpdns.org/auth?tab=register 完成账号注册。

2. 本机设备码

  • 打开窗口时自动生成并显示，为只读，无需也无法手工修改。
  • 注册前请先将其中的字符复制或抄写下来，用于提交注册。

3. 产品注册

  • 登录邮箱：填写接收许可证密钥的邮箱地址。
  • 登录密码：设置该授权账号的密码，输入时显示为 *。
  • 注册按钮：提交注册申请，提交过程中按钮变为「注册中...」。

4. 产品激活

  • 许可证密钥：粘贴从注册邮件中收到的许可证密钥。
  • 激活按钮：提交激活，提交过程中按钮变为「激活中...」，激活成功后窗口自动关闭。
  • 激活时间：本机已激活时显示激活成功的具体时间。

三、注册与激活的操作步骤

步骤 1：取得本机设备码

启动 RC3、完成登录后，弹出「注册与激活」窗口，窗口中部的本机设备码已自动填好一串字符，复制下来备用。

步骤 2：注册账号

有两种方式，任选其一：

方式 A — 在窗口内直接注册

  1. 在「产品注册」区的 登录邮箱 中填写您的邮箱。
  2. 在 登录密码 中设置密码。
  3. 点击 注册。
  4. 出现提示 注册成功！注册码已发送至您的邮箱，请查收。 即表示提交成功。

方式 B — 通过官网页面注册

  1. 点击窗口顶部的链接 「还没有账号？立即注册」。
  2. 浏览器自动打开官网注册页。
  3. 在网页上完成账号注册。
  4. 回到 RC3 窗口，设备码已填好，直接进入下一步激活。
提示 两种方式只需使用其中一种。如果已经在官网注册过账号，回到 RC3 窗口直接进入下一步激活即可。

步骤 3：激活许可证

  1. 打开注册邮箱，找到系统发送的邮件，复制其中的许可证密钥。
  2. 回到「注册与激活」窗口，在 产品激活 区的 许可证密钥 中粘贴（建议使用 Ctrl+V，避免复制时带入多余空格或换行）。
  3. 点击 激活。
  4. 出现提示 产品激活成功！本设备已获得授权。 表示激活完成，注册窗口自动关闭。

步骤 4：确认激活成功

  • 从启动流程进入注册的：激活成功后系统自动进入主界面，可直接开始使用。
  • 再次打开「注册与激活」窗口时：两个按钮显示为 已激活 且不可点击，登录邮箱与登录密码输入框变灰，下方显示 激活时间。

四、打开注册窗口的方式

方式 操作
启动时自动弹出 启动 RC3 并登录后，若本机未激活则自动弹出。
主界面菜单 系统服务(&S) → 注册与激活(&R)

五、常见情形

提示「未激活程序，将退出系统。」

在「未检测到许可证文件，请先注册和激活。」的提示中选择了取消。请重新启动程序，在提示时选择确定进入注册流程。

设备码是空白的

设备码由程序自动读取本机硬件信息生成，当前版本为只读、不能手工输入。请依次尝试：

  1. 关闭「注册与激活」窗口后重新打开；
  2. 重启计算机后再试；
  3. 以管理员身份运行 RC3；
  4. 确认没有被杀毒 / 安全软件拦截；
  5. 虚拟机或精简版系统可能取不到足够的硬件信息，此时程序会自动改用本机持久化标识。

注册失败、激活失败

提示信息 处理办法
注册失败！HTTP … 检查网络能否打开 https://richen.dpdns.org/；确认邮箱格式正确、密码已填写；邮件未收到请检查垃圾邮件；仍失败请记下 HTTP 状态码并联系技术支持。
激活失败！HTTP … 确认密钥完整、无多余空格与换行；确认设备码与申请注册时是同一台机器；确认该密钥未被用于其他设备。
读取激活信息失败，请重新激活。 许可证文件损坏或读取失败。请检查程序目录是否可写（不要装在 Program Files 等受保护目录下），必要时删除程序目录下的 license 文件夹后重新激活。

提示「本设备已激活，无需再次注册或激活。」

这是正常状态，说明本机已完成激活，关闭窗口即可继续使用。

提示「检测到硬件变更，请重新激活」或「检测到硬件变更，设备ID不匹配」

以下操作会导致设备码变化，从而需要重新激活：

  • 更换主板、硬盘、网卡等主要硬件；
  • 重装操作系统；
  • 克隆或迁移硬盘、虚拟机迁移；
  • 恢复系统镜像或更换计算机。

处理方法：在新硬件的这台机器上，用原账号重新注册，获取新的许可证密钥后再次激活。

建议 更换硬件或重装系统前，先在旧环境完成数据备份，并记录好注册邮箱与密码。

升级后是否需要重新激活

许可证保存在程序目录下的 license\license.dat，正常升级不会影响已激活状态。若升级后提示未激活，请按本章第三节重新执行一次激活。

一台电脑能装几套

一个许可证对应一台设备（一个设备码）。多台电脑需各自注册并激活。

忘记密码或更换邮箱

当前版本的注册窗口仅用于申请授权，没有提供「找回密码」入口。请通过公司官网或技术支持邮箱处理。
