一、提示信息速查表

下表列出软件实际弹出的提示文字及其处理办法，可按关键字快速查找。

菜单与权限

现象或提示 处理办法
登录后菜单栏少了很多项 菜单按角色权限显示。请联系系统管理员在角色权限设置中为你的角色补勾相应菜单，然后重新登录。登录账号 ADMIN 始终拥有全部菜单。
整个顶级菜单都不见了 顶级菜单仅在至少有一个下级菜单可见时才显示。该模块整组无权限时顶级菜单会整条隐藏。
登录时「核算单位」下拉框是空的 该操作员没有被授权任何账套。请在操作员权限中为其分配账套权限。

帮助与其他

现象或提示 处理办法
点击「帮助」没有反应，或提示找不到帮助文件 程序目录下的 help\ 文件夹可能缺失。系统会自动改为打开公司官网上的在线帮助；如需离线使用，请将完整帮助文件复制到程序目录下的 help\ 文件夹（含 index.html 与 style.css）。
无法打开公司官网：… 系统未能调用默认浏览器。请按提示中的网址手动在浏览器中打开，并检查本机是否关联了默认浏览器。
程序错误… 操作过程中出现异常。请记下完整提示内容，必要时截图后联系技术支持。

二、功能使用疑问

如何切换当前账套或业务日期？

使用 系统服务(&S) → 重新注册，在登录窗口重新选择核算单位与业务日期后登录。操作前请先保存当前正在录入的单据。

为什么登录后看不到某个我熟悉的菜单？

先确认是否更换过角色或角色权限被调整过。权限在登录时加载，重新登录才会生效。若确认无误，请联系系统管理员查看该角色在角色权限设置中的授权情况。

能否修改登录密码？

可以。使用 系统服务(&S) → 修改密码。管理员为他人重置密码时，需通过「修改操作员」窗口以外的途径按本单位规定处理——该窗口不提供密码字段。

软件如何升级？

程序每 7 天在后台静默检查一次新版本并下载，下次启动时生效；也可手动执行 系统服务(&S) → 在线升级。若涉及数据库结构变更，需再执行「升级RC3数据」或「检测与升级数据库」，建议由系统管理员操作并事先备份数据库。

升级后需要重新激活吗？

一般不需要。许可证保存在程序目录下的 license\license.dat。若升级后提示未激活，请按注册与激活重新激活一次。

换了一台电脑要怎么用？

软件授权与硬件绑定，换机后需在新电脑上用原账号重新注册并激活。详见注册与激活中的「检测到硬件变更」一节。

一台电脑可以安装多套吗？

一个许可证对应一台设备（一个设备码）。多台电脑需各自注册并激活。

程序装在哪个目录比较好？

建议装在有写入权限的本地目录（例如 D:\RC3\），不要装在 Program Files 等受保护目录下，否则保存许可证、升级文件与日志时会失败。
