欢迎使用 RC3 企业管理系统

本帮助说明系统的启动、登录、注册激活、菜单结构与用户权限的基本操作。系统的业务单据操作（采购、销售、库存、财务、成本、总账、期末）请参见随系统提供的各模块说明。

怎么打开本帮助

  • 点击主界面工具栏上的 帮助 按钮；
  • 点击任一窗体菜单栏中的 帮助(&H) → 帮助内容；
  • 点击任一窗体上的 帮助(&H) 按钮；
  • 或直接用浏览器打开程序目录下的 help\index.html。
提示 帮助内容保存在程序目录的 help\ 文件夹内，离线也能查看；若该文件夹缺失，系统会自动改为打开公司官网上的在线帮助。

内容一览

开始使用

数据库服务器准备、首次配置数据源、启动流程与配置文件说明。

登录与账套

登录窗口各字段的含义、账套与业务日期的选择规则。

注册与激活

软件授权的注册与激活步骤、设备码变更的处理办法。

主界面与菜单

菜单栏、工具栏、状态栏的结构，以及菜单权限的显示规则。

用户与权限

新增操作员、分配角色、按角色设置功能与数据权限。

常见问题

各类提示信息的含义与处理办法对照表。

使用约定

约定 含义
菜单 形如 系统服务(&S) → 注册与激活(&R)，表示先选左侧的菜单，再选其下的子菜单。(&) 内为键盘快捷键，按住 Alt 再按该字母即可直接切换菜单。
提示信息原文 表示软件实际弹出的提示文字，可在常见问题中查到处理办法。
程序目录\xxx 指 RC3 可执行文件所在的文件夹。
