登录与账套

一、登录窗口

程序启动并连接数据库成功后，会弹出登录窗口。窗口左下角显示当前软件版本号。

字段 说明
登录账号 由系统管理员分配的登录名，不区分大小写（自动转为大写）。
口令 该账号的登录密码，在数据库中为加密存储。
核算单位 可选择的账套范围由账号权限决定。若该下拉框为空，说明该账号没有被授权任何账套，请联系系统管理员。
业务日期 本次登录所处理的会计期间所属日期。系统据此确定当前会计期，并影响期间校验、期初与结账相关操作。

窗口右下方有三个按钮：确定(&O) 登录、帮助(&H) 打开本帮助、退出(&X) 退出系统。

提示 输入时按 Enter 键等同于按「Tab」键，可以直接在几个输入框之间快速跳转。

二、登录时可能出现的提示

提示信息 处理办法
登录帐号不存在。 核对登录账号拼写；确认该账号未被停用或删除。
密码错误，请重新输入。 重新输入口令。连续 3 次密码错误后系统会自动退出，需重新启动程序。
您没有操作权限，请与系统管理员联系。 该账号没有分配任何角色，请联系系统管理员在用户角色中为其分配角色。
没有符合条件的会计期间。请检查会计期间设置。 所选业务日期在系统中没有对应的会计期间，请改选已建立会计期间的日期，或先由管理员建立新年度账。

三、账套（核算单位）说明

  • 一个账套对应一个核算单位（如某某公司、某某工厂），各自拥有独立的业务数据与会计期间。
  • 登录后可在下拉框中切换选择，能选到哪些账套由系统管理员为该账号授权决定。
  • 登录窗口中的业务日期与账套共同确定本次工作的会计期，请按实际业务需要选择。
  • 进入系统后，主界面右下角状态栏会显示当前单位与登陆日期，可随时确认是否选错。

四、重新登录

已登录后如需更换账号或账套，使用主界面菜单 系统服务(&S) → 重新注册，将重新回到本登录窗口。

注意 重新登录前请确认当前已录入的单据均已保存，否则未保存的内容会丢失。
