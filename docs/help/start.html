开始使用

一、启动前需要准备什么

RC3 是基于 Oracle 数据库的客户端系统，服务器与客户端必须都就绪才能使用。

项目 要求
数据库服务器 Oracle 数据库已安装并处于启动状态，监听服务可用，端口为 1521。
数据库账号 一个可连接该数据库的用户名与口令，需已具备该账套各业务表的操作权限。
客户端 Windows 电脑，已安装 .NET Framework 4.8，能访问数据库服务器所在网络。
网络 能访问公司官网 https://richen.dpdns.org/，用于在线升级与软件注册激活。
注意 如果客户端连不上数据库服务器，登录时会出现对不起，数据库服务器连接不上。请稍后再试或与系统管理员联系。此时程序会直接退出，请先确认服务器与网络正常。

二、首次运行：配置数据源

RC3 第一次在一台电脑上运行时，会自动弹出数据源配置窗口，按提示填写以下内容：

配置项 说明
数据库服务器 Oracle 服务器的地址或主机名。
数据库名称 Oracle 的服务名（Service Name），不是 SID。
用户名 / 口令 连接该数据库所用的账号与密码。

配置完成后会保存为程序目录下的配置文件 richen.config，其中的内容是加密存储的，请勿手工编辑或删除。

提示 需要更换数据库或服务器时，直接删除程序目录下的 richen.config 后重新启动程序，即可再次弹出配置窗口。

三、启动流程

  1. 双击运行 RC3。
  2. 程序自动检查是否有新版本（每 7 天检查一次，在后台静默执行，不影响使用）。
  3. 读取数据源配置。若尚未配置，弹出数据源配置窗口；配置成功则继续。
  4. 连接数据库服务器。连接失败会提示并退出。
  5. 弹出登录窗口，请输入登录账号与口令。
  6. 若本机尚未授权，会弹出注册与激活窗口，请按注册与激活完成授权后进入系统。
  7. 登录成功后进入主界面。

四、程序目录中常见的文件夹

名称 用途
help\ 本帮助文件所在目录。
license\ 软件激活后生成的许可证文件，请勿删除或改动。
richen.config 数据库数据源配置（加密存储）。
update.config 在线升级检查的配置与上次检查时间。
reports\ 报表模板文件。
images\ 主界面背景图片等资源。
注意 请把程序安装在有写入权限的目录（例如 D:\RC3\），不要装在 Program Files 等受系统保护的目录下，否则保存许可证与升级文件时会失败。
