用户与权限

本章读者 本章内容仅供系统管理员使用。系统采用「操作员 → 角色 → 菜单/数据权限」的三层授权结构：先给操作员分配角色，再给角色勾选可用的功能菜单与数据范围，操作员登录后即拥有其所有角色的权限之和。

一、权限模型

层次 作用 维护入口
操作员 系统的实际使用者，一个操作员可以属于多个角色。 系统设置(&B) → 操作员和操作员角色设置
角色 权限的载体，把一批菜单权限与数据权限打包，便于批量授权。 系统设置(&B) → 角色和角色操作权限设置
菜单权限 决定登录后能看到哪些菜单、打开哪些功能窗体。 用户角色窗口 → 权限(&V)
数据权限 决定可见的账套、类别、部门、单据类型。 操作员管理窗口 → 权限(&V)

二、操作员管理

入口：系统设置(&B) → 操作员和操作员角色设置，窗口标题为「操作员管理」。

列表显示三列：登录账号、全名、所属单位。窗口上方的按钮为：

按钮 说明
增加(&A) 新增一个操作员，详见下节。
修改(&E) 修改选中操作员的登录账号、全名与所属单位。
权限(&V) 打开所选操作员的权限设置，分配角色与数据权限。
删除(&D) 删除所选操作员，同时清除其全部数据权限记录。
输出 把操作员列表导出为 Excel 文件。
帮助(&H) 打开本帮助。
注意 删除操作员会一并删除其数据权限记录。若该操作员已离职，建议改为取消其所有角色，保留账号记录以便追溯历史单据的操作人。

三、增加操作员

字段 说明
登陆账号 登录名，保存时自动转为大写，长度不超过 30 个字符。
全名 操作员姓名，会显示在主界面状态栏与单据的制单人处，长度不超过 30 个字符。
密码 登录口令，加密后存储，界面上不显示明文。
密码确认 再次输入密码以确认。
所属单位 该操作员所属的核算单位编码。
易错点 「密码」与「密码确认」必须完全一致（区分前后空格）。若两次输入不一致，窗口会直接关闭且不保存，请重新打开「增加操作员」窗口，仔细核对后再保存。

四、修改操作员与修改密码

  • 「修改操作员」窗口可改 登陆账号、全名、所属单位，不含密码。
  • 修改自己的密码请使用主界面菜单 系统服务(&S) → 修改密码。
  • 操作员登录时连续 3 次密码错误会触发程序自动退出，需重新启动。

五、用户的角色与数据权限

在「操作员管理」中选中一个操作员，点击 权限(&V)，可为其分配：

权限类型 作用
角色 从系统已有的角色中挑选分配给该操作员，可分配多个。一个操作员拥有其所有角色授予的菜单权限。
账套 分配该操作员可使用的核算单位。直接决定登录窗口中「核算单位」下拉框里能看到哪些账套。
类别 限制该操作员可操作的物料、客户、供应商等类别范围。
部门 限制该操作员可涉及的部门范围。
单据类型 限制该操作员可使用的单据类型范围。
提示 分配账套权限是让操作员能登录某个账套的前提。若登录时「核算单位」下拉框为空，请先回到这里为其分配账套。

六、用户角色（角色维护）

入口：系统设置(&B) → 角色和角色操作权限设置，窗口标题为「用户角色」。

窗口按钮：增加(&A)、修改(&E)、权限(&V)、删除(&D)、输出、帮助(&H)、退出(&X)。

角色编辑窗口

字段 说明
角色编码 角色的唯一标识，保存时自动转为大写并去除首尾空格。
输入框最多可输入 19 个字符，但数据表字段长度为 12，故请控制在 12 个字符以内。编码重复时无法保存，请换一个。
角色名称 角色的显示名称，最多 30 个字符，例如「财务主管」「仓库管理员」。该名称会参与下方「记忆码」的自动生成。
记忆码 便于检索与识别的简码，最多 12 个字符，保存时转为大写。新增角色时系统会依据角色名称的拼音首字母自动生成，可自行修改。

窗口按钮为 新增、编辑、保存、取消、返回。

注意 角色编码一旦被操作员引用或已设置过权限，便不宜再修改，以免权限失效。若角色下仍有操作员或仍配置了菜单权限，系统会阻止删除，请先解除关联。

七、角色权限设置

在「用户角色」窗口中选中一个角色，点击 权限(&V)，打开「角色权限设置」窗口。窗口左侧为预选功能权限列表，右侧为已选功能权限列表（即该角色当前已拥有的菜单）。两个列表之间有四个箭头按钮。

按钮 作用
-->>把左侧选中的菜单全部加入已选功能权限
-->把左侧选中的菜单加入已选功能权限
<--把右侧选中的菜单移出已选功能权限
<<--把右侧选中的菜单全部移出已选功能权限

除箭头按钮外，直接双击列表中的菜单项也可完成添加或移出，操作更快捷。

  1. 在左侧「预选功能权限」中选中需要的菜单（可按住 Ctrl 多选），点击 --> 移到右侧；
  2. 若要把左侧某类菜单全部加入，点击 -->>；
  3. 在右侧「已选功能权限」中选中不再需要的菜单，点击 <-- 移回左侧；
  4. 核对左右两侧的最终结果后，点击窗口右下角的确定按钮保存。
重要 确定保存时，系统会以该角色当前右侧的列表整体覆盖原有的菜单权限。因此请先核对两侧的最终结果再保存，避免误删既有权限。

八、让权限立即生效

菜单权限在登录时根据操作员的角色一次性加载，因此调整角色权限后：

  1. 请让相关操作员使用 系统服务(&S) → 重新注册，或退出后重新登录；
  2. 若调整的是自己的角色权限，也需重新登录才能看到变化；
  3. 登录账号为 ADMIN 时始终拥有全部菜单，不受角色权限影响。

九、推荐的授权步骤

  1. 先在「用户角色」中建立角色，例如「仓管员」「采购员」「财务主管」。
  2. 为每个角色设置菜单权限，只勾选该岗位真正需要的菜单。
  3. 在「操作员管理」中新增操作员，填写账号、全名、初始密码、所属单位。
  4. 为每个操作员分配角色。
  5. 为每个操作员分配账套权限，否则登录时看不到任何核算单位。
  6. 按需要进一步细分类别、部门、单据类型权限。
  7. 通知操作员重新登录，并确认菜单显示符合预期。
