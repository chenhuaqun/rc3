## 1. 概述

### 1.1 为什么需要注册与激活

RC3 企业管理系统为授权使用软件。首次在一台新电脑上运行时，系统中还没有本机的许可证，启动时会提示：

> 未检测到许可证文件，请先注册和激活。

完成 **注册账号** 与 **激活许可证** 两步之后，才能进入系统主界面。

### 1.2 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows（本版本为 Windows 桌面客户端） |
| 网络 | 需能访问互联网，公司网址 <https://richen.dpdns.org/> |
| 邮箱 | 一个可正常收信的登录邮箱（用于接收许可证密钥） |
| 数据库 | 数据库服务器地址可用（启动时需先连接数据库并登录） |
| 目录权限 | RC3 程序所在目录需要可写权限（用于保存许可证文件） |

### 1.3 「注册」与「激活」的区别

| | 注册 | 激活 |
| --- | --- | --- |
| 作用 | 提交邮箱与设备码，向公司申请授权 | 用收到的许可证密钥为本机授权 |
| 输入内容 | 登录邮箱、登录密码 | 许可证密钥 |
| 结果 | 许可证密钥发送到注册邮箱 | 本机获得授权，程序可正常使用 |
| 入口 | 「注册与激活」窗口 → 产品注册 | 「注册与激活」窗口 → 产品激活 |

> **注意**：此处注册的账号是 **RC3 软件的授权账号**，与系统内部的操作员登录账号是两回事，两者互不影响。

## 2. 名词说明

| 名词 | 含义 | 出现位置 |
| --- | --- | --- |
| 账号 | RC3 软件的授权账号，由登录邮箱 + 登录密码组成 | 注册窗口「产品注册」区 |
| 本机设备码 | 由本机硬件信息计算出的唯一标识（一串 64 位字符） | 注册窗口「本机设备码」，只读不可修改 |
| 许可证密钥 | 注册成功后发送到注册邮箱的授权码 | 邮件正文 → 注册窗口「产品激活」区 |
| 许可证文件 | 激活成功后保存在程序目录下的授权记录 | `程序目录\license\license.dat` |

## 3. 注册与激活总流程

```
启动 RC3
   ↓
连接数据库 → 登录系统（操作员账号）
   ↓
系统检测本机许可证
   ├─ 已激活且设备码一致 ──→ 进入主界面
   └─ 未检测到 / 设备码不一致 ──→ 弹出「注册与激活」窗口
                                    ↓
                          ① 记下窗口中的本机设备码
                                    ↓
                          ② 注册账号（窗口内注册 或 官网页面注册）
                                    ↓
                          ③ 从注册邮箱中复制许可证密钥
                                    ↓
                          ④ 粘贴到「许可证密钥」→ 点击「激活」
                                    ↓
                          激活成功，窗口自动关闭 → 进入主界面
```

完整步骤说明见 [第 5 章](#5-分步操作)。

## 4. 「注册与激活」窗口说明

窗口标题为 **注册与激活**，从上到下分为四个区域：

### 4.1 账号注册

| 控件 | 说明 |
| --- | --- |
| 链接「还没有账号？立即注册」 | 点击后自动打开浏览器，进入官网注册页 <https://richen.dpdns.org/auth?tab=register> 完成账号注册 |

> 该链接为**新增功能**。如果您的版本窗口上没有「账号注册」这一栏，请升级到较新版本。

### 4.2 本机设备码

| 控件 | 说明 |
| --- | --- |
| 文本框「本机设备码：」 | 打开窗口时自动生成并显示，**只读**，无需也无法手工修改 |

该文本框可完整显示设备码，注册前请先将其中的字符复制或抄写下来，用于提交注册。

### 4.3 产品注册

| 控件 | 说明 |
| --- | --- |
| 「登录邮箱：」 | 填写接收许可证密钥的邮箱地址 |
| 「登录密码：」 | 设置该授权账号的密码，输入时显示为 `*` |
| 「注册」按钮 | 提交注册申请；提交过程中按钮变为「注册中...」 |

### 4.4 产品激活

| 控件 | 说明 |
| --- | --- |
| 「许可证密钥：」 | 粘贴从注册邮件中收到的许可证密钥 |
| 「激活」按钮 | 提交激活；提交过程中按钮变为「激活中...」，激活成功后窗口自动关闭 |
| 「激活时间：」 | 本机已激活时显示激活成功的具体时间 |

## 5. 分步操作

### 5.1 步骤一：取得本机设备码

1. 启动 RC3，完成数据库配置与登录。
2. 弹出「注册与激活」窗口后，窗口中部的 **本机设备码** 文本框已自动填好一串字符。
3. 复制这串字符（注册时需与账号一并提交）。

> 设备码是空白的？请直接查看 [7.2 设备码为空](#72-设备码为空或提示无法获取设备码)。

### 5.2 步骤二：注册账号

有两种方式，任选其一。

#### 方式 A：在窗口内直接注册

1. 在「产品注册」区的 **登录邮箱** 中填写您的邮箱。
2. 在 **登录密码** 中设置密码。
3. 点击 **注册**。
4. 出现提示 **注册成功！注册码已发送至您的邮箱，请查收。** 即表示提交成功，密码框会自动清空。

#### 方式 B：通过官网页面注册

1. 点击窗口顶部的链接 **「还没有账号？立即注册」**。
2. 浏览器自动打开官网注册页 <https://richen.dpdns.org/auth?tab=register>。
3. 在网页上完成账号注册。
4. 回到 RC3 的「注册与激活」窗口，**本机设备码** 已经填好，继续下一步激活。

> 两种方式只需使用其中一种即可；如果已经在官网注册过账号，回到 RC3 窗口直接进入下一步激活。

### 5.3 步骤三：激活许可证

1. 打开注册邮箱，找到系统发送的邮件，复制其中的许可证密钥。
2. 回到「注册与激活」窗口，在 **产品激活** 区的 **许可证密钥** 中粘贴（建议使用 `Ctrl+V`，避免复制时带入多余空格或换行）。
3. 点击 **激活**。
4. 出现提示 **产品激活成功！本设备已获得授权。** 表示激活完成，注册窗口自动关闭。

### 5.4 确认激活成功

- 从启动流程进入注册的：激活成功后系统自动进入主界面，可直接开始使用。
- 已激活状态下再次打开「注册与激活」窗口时：
  - 两个按钮显示为 **已激活** 且不可点击；
  - **登录邮箱**、**登录密码** 输入框变灰不可编辑；
  - 窗口下方显示 **激活时间：yyyy-MM-dd HH:mm:ss**。

## 7. 常见问题

### 7.1 启动时提示「未检测到许可证文件，请先注册和激活」，我点了「取消」会怎样？

系统会继续提示 **未激活程序，将退出系统。** 并退出 RC3。请重新启动程序，在提示时选择「确定」进入注册流程。

### 7.2 设备码为空或提示「无法获取设备码」

设备码由程序自动读取本机硬件信息生成，**当前版本为只读，不能手工输入**。请依次尝试：

1. 关闭「注册与激活」窗口后重新打开；
2. 重启计算机后再试；
3. 以**管理员身份**运行 RC3；
4. 确认没有被杀毒/安全软件拦截；
5. 虚拟机或精简版系统可能取不到足够的硬件信息，此时程序会自动改用本机持久化标识。

仍无法生成，请联系技术支持，并提供计算机型号与操作系统版本。

### 7.3 注册失败，提示「注册失败！HTTP …」

| 检查项 | 说明 |
| --- | --- |
| 网络连通 | 浏览器能否打开 <https://richen.dpdns.org/> |
| 邮箱格式 | 是否为完整、正确的邮箱地址 |
| 密码 | 是否已填写（不能为空） |
| 邮件未到 | 检查垃圾邮件 / 广告邮件文件夹；确认邮箱地址无误 |
| 仍失败 | 记下窗口中显示的 HTTP 状态码，联系技术支持 |

### 7.4 激活失败，提示「激活失败！HTTP …」

1. 确认许可证密钥**完整、无多余空格和换行**（建议直接粘贴邮件原文）；
2. 确认设备码与申请注册时是**同一台机器**；
3. 确认该密钥没有被用于其他设备（一个密钥对应一台设备）；
4. 确认网络正常。

### 7.5 提示「本设备已激活，无需再次注册或激活。」

这是**正常状态**，说明本机已完成激活。关闭窗口即可继续使用；若想查看激活时间，可通过 **系统服务(&S) → 注册与激活(&R)** 打开窗口查看。

### 7.6 提示「检测到硬件变更，请重新激活」或「检测到硬件变更，设备ID不匹配」

以下操作会导致设备码变化，从而需要重新激活：

- 更换主板、硬盘、网卡等主要硬件；
- 重装操作系统；
- 克隆或迁移了硬盘 / 虚拟机迁移；
- 恢复系统镜像或更换计算机。

处理方法：在**新硬件的这台机器**上，用原账号重新注册，获取新的许可证密钥后再次激活。

> 建议：更换硬件或重装系统前，先在旧环境完成数据备份，并记录好注册邮箱与密码。

### 7.7 提示「读取激活信息失败，请重新激活」

说明许可证文件损坏或读取失败。请检查：

1. 程序所在目录是否可写（不要安装在 `Program Files` 等受保护目录下）；
2. 删除程序目录下的 `license` 文件夹后重新启动程序、重新激活。

### 7.8 激活完成后还需要再操作吗？

不需要。激活成功后注册窗口会自动关闭。

- 启动流程中注册的：直接进入主界面；
- 从菜单打开注册的：关闭窗口后继续正常使用即可。

### 7.9 软件升级后需要重新激活吗？

许可证保存在程序目录下的 `license\license.dat`，正常升级不会影响已激活状态。若升级后提示未激活，请按 [第 5 章](#5-分步操作) 重新执行一次激活。

### 7.10 一台电脑可以安装几套？

一个许可证对应**一台设备**（一个设备码）。多台电脑需各自注册并激活。

### 7.11 更换电脑怎么办？

在新电脑上重新注册账号并激活即可。旧电脑的授权随硬件变更而失效，不再可用。

### 7.12 忘记密码或更换邮箱怎么办？

当前版本的注册窗口仅用于申请授权，没有提供「找回密码」入口。请通过官网或技术支持邮箱（见 [第 9 章](#9-技术支持信息)）处理。

### 7.13 怎么确认自己用的是最新版本？

- 登录窗口底部会显示当前版本号；
- 进入 **系统服务(&S) → 关于(&A)**，窗口中显示「软件版本」。

| 激活失败！HTTP … | 激活请求被拒绝 | 见 [7.4](#74-激活失败提示激活失败http-) |
| 注册时发生错误：… | 注册过程异常 | 记下错误内容并联系技术支持 |
| 激活时发生错误：… | 激活过程异常 | 记下错误内容并联系技术支持 |
| 无法打开浏览器，请手动访问：… | 系统未能自动打开浏览器 | 手动复制该网址到浏览器中打开 |
